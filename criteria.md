# Evaluation Criteria for Guideline Analysis

1. Include information about encryption during data transfer.
1. Specify whether user data can be deleted.
1. Specify whether user data is automatically deleted within 90 days.
1. Use data names that align with the official terminology.
1. Use only data categories that are part of the official classification.
1. Ensure consistency with the official mapping between data categories and data types.
1. Describe both data actions: collection and sharing.
1. Clearly state whether data is shared beyond the app developer's domain.
1. Clarify whether data collection occurs when optional data sharing is offered.
1. Specify when ephemeral data processing is used.
1. Avoid stating that sharing is optional (it cannot be declared in the Data Safety section).
1. State the purpose of data collection.
1. State the purpose of data collection for all mentioned data types.
